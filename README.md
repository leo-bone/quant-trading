# Binance 量化交易系统

三级量化交易系统，支持现货和杠杆合约交易。

## 系统概览

| 级别 | 资金 | 策略 | 交易模式 |
|------|------|------|---------|
| L1 | $10,000 | 网格策略 | 现货 |
| L2 | $100,000 | 三角套利 | 现货 + 合约 |
| L3 | $1,000,000 | 多策略组合 | 现货 + 合约 |

## 快速开始

### 1. 安装依赖

```bash
cd quant_trading
pip install -r requirements.txt
```

### 2. 配置 API 密钥

```bash
cp .env.example .env
# 编辑 .env 填入你的 Binance API 密钥
```

**获取测试网密钥（推荐先用）:**
1. 访问 https://testnet.binance.vision/
2. 登录后生成 API 密钥
3. 填入 .env 文件

### 3. 运行系统

```bash
# 方式1: 交互式启动
python run.py

# 方式2: 直接启动指定级别
python -m l1_10k.main   # L1 系统
python -m l2_100k.main  # L2 系统
python -m l3_1m.main    # L3 系统
```

## 策略说明

### L1: 网格策略
- 在固定价格区间设置买卖网格
- 适合震荡行情
- 风险较低，收益稳定

### L2: 三角套利
- 利用现货-合约价差套利
- 同时操作现货和合约
- 需要较快执行速度

### L3: 多策略组合
- 趋势跟踪 + 均值回归 + 突破
- 策略投票决定执行
- 分散风险，收益最大化

## 风险控制

每个系统都内置:
- 单笔止损 (1-2%)
- 日内最大亏损限制
- 仓位上限控制
- 自动停止交易机制
